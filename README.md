# Orbit · Central de contatos

Aplicação de lista de contatos criada com React para o exercício da EBAC.

## Funcionalidades

- Lista de contatos com nome completo, e-mail e telefone;
- Adicionar novos contatos;
- Editar dados de contatos existentes;
- Remover contatos;
- Buscar por nome, e-mail ou telefone;
- Persistência automática no `localStorage` do navegador.

## Tecnologias

- React + Vite;
- Redux Toolkit e React Redux;
- Styled Components;
- Lucide React.

## Como executar

```bash
npm install
npm run dev
```

Para validar o build de produção:

```bash
npm run lint
npm run build
```
